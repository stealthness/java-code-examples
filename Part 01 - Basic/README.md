# PART 1 - THE BASICS

In part 1 will cover the basic concepts of programming in Java. These basic are building blocks of programming and 
except for differences in syntax, are common to most programming languages.

The topics covered in this part are:

+ Writing, compiling and running a Java program
+ Basic Java flow control covering `if`, `else if`, `else`, `while`, `do...while`, `for` and `switch` statements.
+ Basic Java data types and variables, including `int`, `double`, `boolean`, `char` and `String`.
+ Basic Java operators including arithmetic, relational and logical operators.
+ Basic Java methods including method declaration, method parameters and return values.
